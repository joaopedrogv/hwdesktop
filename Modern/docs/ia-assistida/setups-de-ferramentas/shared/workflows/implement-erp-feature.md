# Implement ERP Feature

1. Read `AGENTS.md` and `.ai/commands/implement-erp-feature.md` completely.
2. Follow the canonical Command and every artifact it selects.
3. Treat the developer's informal feature request in the current conversation as
   input. If it has not been provided, ask for it before starting discovery.
4. Preserve all canonical approval and authorization gates. Invoking this Workflow
   does not approve implementation or authorize build and test execution.
