# Integrações pendentes de ferramentas de IA

Este diretório preserva material preliminar de integrações que ainda não foram
reconciliadas com o modelo operacional e com a automação canônica dos setups.

Os arquivos aqui não são adapters ativos, não devem ser copiados manualmente para
a raiz e podem conter hipóteses antigas de configuração ou de modelos. Antes de
reativar uma ferramenta, confirmar seu formato atual, revisar os cinco papéis
canônicos e incorporá-la a `Scripts/AI/Sync-AIProfiles.ps1`.

- `opencode/` — adapters preliminares anteriormente mantidos em `.opencode/`;
- `codex/` — adapters preliminares anteriormente mantidos em `.codex/`.
